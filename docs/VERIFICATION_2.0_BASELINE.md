## 45 групп сетевых сценариев

Полный вывод: `NETWORK_TESTS.txt`; исходник: `tests/test_gost.py`.

Стенд использует только loopback и временные тестовые сертификаты. Проверены SOCKS5 username/password, отказ анонимной/неверной авторизации, HTTP 407, передача 1 MiB без изменения, HTTP absolute URI и chunked POST, удаление Proxy-Authorization и hop headers, CONNECT с TLS до сайта. Проверены точный разрешённый IPv4, отказ другого исходного IP, общий лимит соединений SOCKS/HTTP и восстановление после освобождения места.

Проверены HTTPS-прокси и SOCKS/TLS с доверенным сертификатом, отказ клиента при недоверенном сертификате, SOCKS5 UDP ASSOCIATE в заданном диапазоне, DNS через UDP, фильтрация UDP по исходному IP, разрешение домена UDP-назначения. Локальный DNS проверен по UDP и TCP, с UDP/TCP upstream.

Цепочки проверены через SOCKS5 и HTTP CONNECT с отдельными учётными данными, передачей домена внешнему прокси, независимым прямым портом, маршрутизацией TLS-входа через upstream. UDP проверен через стандартный SOCKS upstream; для HTTP upstream подтверждён отказ. После остановки каждого upstream несколько повторных запросов не получают прямой обходной маршрут.

Для DoT и DoH проверены успешное разрешение с доверенным сертификатом и отказ с недоверенным. Занятый порт даёт ошибку старта. Все дочерние процессы теста завершаются, все тестовые порты освобождаются. Внутренние метрики требуют отдельную авторизацию и не выдают тестовый пароль.

## Клиентский пример и сертификат

`CLIENT_TLS_TEST.txt` относится к `tests/test_client_template.py`. Генератор создаёт реальный self-signed leaf certificate для 127.0.0.1. Шаблон `examples/client-socks-tls.json` заполняется временными тестовыми значениями; локальные SOCKS5 и HTTP передают трафик через GOST TLS к серверу. Сертификат явно доверен и проверяется клиентом. Это не тест Windows ACL; её код собран для Windows и просмотрен отдельно.

## Сборка Windows

`WINDOWS_BUILD.json` содержит SHA-256 EXE, точные хеши исходников/проекта, импорты и ресурсы. `WINDOWS_BUILD_LOG.txt` — журнал компилятора. Компилятор GCC 14.2 MinGW-w64, статические GCC/C++/winpthread runtime. Импорт `msvcrt.dll` относится к системному CRT Windows; отдельных MinGW DLL не требуется.

**MSBuild/Visual Studio фактически не запускались**, поскольку среда Linux. Файлы .sln/.vcxproj и путь копирования компонентов проверены структурно, а тот же список производственных исходников собран кросс-компилятором. CMake также включён как альтернативный способ сборки.

Попытка графического запуска через Wine была невозможна из-за ограничений IPC среды. Она не выдаётся за проверку окна. DPI, прокрутка, поля и обработчики проверены статически, но фактическое отображение и управление на Windows здесь не наблюдались.

## Практические пределы

Успешный локальный тест не гарантирует пропускную способность VDS, отсутствие фильтрации у хостинга, доступность Telegram из конкретной сети или работу UDP у купленного провайдера. Сначала проверяйте новую сборку на свободных портах рядом со старым рабочим прокси. Программа не требует глобального сброса сетевых правил и не меняет RDP.
